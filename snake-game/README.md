# 🐍 Juego de la Culebrita

Juego clásico de Snake desarrollado con **HTML, CSS y JavaScript puro**. Totalmente responsive y optimizado para desktop y smartphones.

## 🎮 Cómo Jugar

- **Flechas del teclado** (desktop): Controla la dirección de la serpiente
- **D-pad móvil** (smartphone): Toca los botones direccionales
- **Espacio**: Pausa/Reanuda el juego
- Come las 🍎 manzanas para aumentar puntuación
- Evita chocar con las paredes y contigo mismo

## ✨ Características

✅ Sistema de 5 niveles de velocidad progresiva  
✅ Puntuación y niveles dinámicos  
✅ Controles táctiles optimizados para móvil  
✅ Interfaz responsiva (desktop, tablet, móvil)  
✅ Diseño moderno con gradientes y animaciones  
✅ Sin dependencias externas  

## 🚀 Uso

1. Abre `index.html` en tu navegador
2. Presiona "Iniciar Juego"
3. ¡Diviértete!

## 📊 Sistema de Puntuación

- **+10 puntos** por cada manzana comida
- **Nivel nuevo** cada 25 puntos
- **Velocidad aumenta** con cada nivel
- Máxima dificultad: 🔥 ¡EXTREMA! a nivel 10

## 📱 Compatibilidad

✓ Chrome, Firefox, Safari, Edge  
✓ iOS y Android  
✓ Tablets y desktop  

## 📄 Archivos

- `index.html` - Estructura del juego
- `styles.css` - Estilos responsivos
- `script.js` - Lógica del juego
